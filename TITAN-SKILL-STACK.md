# Titan Skill + Tool Stack

## Use these skills by default for storefront work

### Core local skills
- `frontend-design` — visual system, layout direction, component polish
- `page-cro` — conversion friction, CTA hierarchy, shoppability
- `direct-response-copy` — product copy, offer framing, buyer-language CTAs
- `web-design-guidelines` — UX/accessibility/best-practice checks
- `quality-check` — screenshot QA before showing or shipping

### Added external skills
- `storefront-best-practices` — use for homepage, catalog, nav, cart, checkout, mobile storefront UX
- `product-page-design` — use for PDP structure, quantity controls, trust, sticky buying flow
- `conversion-rate-optimization` — use when the site feels weak or confusing and needs prioritized fixes
- `ui-ux-pro-max` — use for hierarchy, spacing, interaction polish, and broader UI quality control

## Tool routing
- `read` / filesystem tools — inspect current code before changing anything
- `edit` / `apply_patch` — surgical implementation
- `browser` — live screenshots, cart flow checks, visible proof
- `web_fetch` — pull external design/skill references quickly
- `exec` — build, typecheck, git, local dev server (currently blocked by runtime module issue)

## Titan storefront standards
1. Treat the site like a buying system, not a brochure.
2. Cart must be visible and understandable.
3. Checkout/payment copy must sound buyer-natural.
4. Shipping/payment/destination rules must be obvious before purchase.
5. Global ordering must have a clear path, including `Other` destination handling.
6. Never claim success without proof.
