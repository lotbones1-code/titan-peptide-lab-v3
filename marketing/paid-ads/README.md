## Quick Start

1. Read `compliance-guide.md` first — peptides trigger ad policy reviews
2. Set up tracking per `tracking-plan.md`
3. Launch Google Search campaigns first (highest intent)
4. Launch Meta retargeting 1 week after search goes live
5. Scale Meta prospecting once you have pixel data

## Key Numbers

- **6 nasal spray SKUs** ranging $59.99–$74.99
- **AOV target:** $65–$120 (single spray to stack)
- **Target CPA:** $25–$40 (Google Search), $15–$30 (Meta retargeting)
